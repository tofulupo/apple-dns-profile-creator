# Security

To report a security problem in the desktop app, the website at mobileconfig.io
or the profiles they build, write to
[security@mobileconfig.io](mailto:security@mobileconfig.io). Please don't open a
public issue for it.

Encrypt the message if you can. The key for the address is published through
OpenPGP WKD, so most mail clients find it on their own, and at
<https://mobileconfig.io/.well-known/openpgpkey/hu/t5s8ztdbon8yzntexy6oz5y48etqsnbb>.
You can also get it from <https://keys.openpgp.org/>. Its fingerprint is
`AA23 481C C247 1713 397A 15F2 B043 6CEA 3CE0 EE5E`.

English or German. The same contact is in
<https://mobileconfig.io/.well-known/security.txt> (RFC 9116, signed).

Fixes don't wait for the next planned release. They go out as soon as possible,
and the changelog says what was fixed once it's out. Say in your report if and
how you want to be credited there.
